🧪 Test Zalo Chat Widget

📋 Hướng dẫn test:

  • 1. Nhìn góc phải dưới màn hình - bạn sẽ thấy nút chat màu xanh
  • 2. Click vào nút chat để mở chat window
  • 3. Gửi tin nhắn test để kiểm tra chức năng
  • 4. Test các nút quick action (Mở Zalo, Copy số)
  • 5. Mở Developer Tools (F12) để xem console log

🔍 Kiểm tra Console:

  • Mở Developer Tools (F12)
  • Vào tab Console
  • Sẽ thấy: "🎉 Zalo Chat Widget đã được load trực tiếp!"
  • Và: "📱 Widget sẽ hiển thị ở góc phải dưới màn hình"

📱 Responsive Test:

  • Thay đổi kích thước cửa sổ browser
  • Widget sẽ tự động điều chỉnh
  • Test trên mobile view (F12 > Toggle device toolbar)

Nếu bạn thấy nút chat màu xanh ở góc phải dưới → Widget hoạt động! 🎉
